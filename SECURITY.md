# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's private vulnerability reporting feature for this repository. Include the affected version, a description of impact, and steps to reproduce where safe. Do not include real credentials, private keys, or sensitive customer data.

The maintainers will acknowledge a report as soon as practical, investigate it privately, and coordinate a fix and disclosure with the reporter.

## Scope

Security reports may concern URL fetching, parsing, denial-of-service risks, or unsafe handling of TOML and command output. This tool validates metadata; it does not validate the safety or trustworthiness of a Stellar issuer.
